> What does provisioning looks like

The one-time Xcode ritual to get the app onto your physical iPhone + Watch:

1. Signing. Xcode → Settings → Accounts → add your Apple ID. In the project, select the Cue target → Signing & Capabilities → check "Automatically manage signing" and pick your Personal Team; same for the watch target. The bundle IDs (com.jasoneplumb.cue / .watchkitapp) are already set. Free-tier caveat: a personal team's provisioning profile expires every 7 days — the app stops launching until you re-run from Xcode. Fine for the first ride or two; the $99/yr Developer Program gives year-long profiles and is worth it before the 10-ride study.
2. Devices. Plug in the iPhone (or pair over Wi-Fi), enable Developer Mode on it (Settings → Privacy & Security → Developer Mode, reboots), and the same on the watch. First install, you'll also trust your developer certificate on-device (Settings → General → VPN & Device Management).
3. Run. Select the Cue scheme with your iPhone as destination and hit Run; the watch app rides along with the phone install. Grant location permission when the app asks (the usage string is already in the build settings).
4. The two documented capabilities — these are why the ride screen currently says "keep the screen on":
  - Background location (phone): Cue target → Signing & Capabilities → + Capability → Background Modes → check Location updates. One matching code change goes with it (allowsBackgroundLocationUpdates = true — the code deliberately doesn't set it yet, because setting it without the capability crashes). Until then, rides work with the screen on and the phone mounted or in a pocket unlocked.
  - Watch runtime session: the watch's "Ride mode" toggle uses WKExtendedRuntimeSession, which needs its session type declared under the watch target's Background Modes. Honest fork ahead: the extended-runtime types Apple offers (self-care, mindfulness, etc.) are all a slightly awkward fit — the natural fit for a bike ride is a real workout session (HealthKit capability), which is what the RFC named. That's a small follow-up decision at provisioning time; either keeps the watch awake enough to feel the tap.
5. Region import. Once running, fetch your loop's Overpass extract (the same out geom; query osm_tag_audit.sh documents), AirDrop or save the JSON to the phone, and load it via the app's "Import region…" picker. It parses, scores, caches — and the Start Ride button goes live.
